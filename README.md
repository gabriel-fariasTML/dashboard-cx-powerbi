# Dashboard Customer Experience — Power BI

Dashboard interativo de análise de atendimento ao cliente desenvolvido com Power BI.

# Ferramentas utilizadas
- Power BI Desktop
- DAX
- Modelagem de dados

# Visão Geral
O dashboard conta com 2 páginas:

*Página 1 — Geral*
- KPIs: Tempo Médio de Atendimento, Total de Atendimentos, Taxa de Resolução e NPS;
- Total de Atendimentos por Canal (WhatsApp, E-mail, Chat, Telefone);
- Evolução Mensal de Atendimentos;
- Total de Atendimentos por Resolução.

*Página 2 — Análise por Cidade*
- Total de Atendimentos por Cidade;
- NPS por Cidade;
- Tabela detalhada com Total de Atendimentos, NPS e Taxa de Resolução por cidade.

# Principais insights
- WhatsApp é o canal com maior volume de atendimentos;
- Taxa de resolução geral de 66%;
- Maracanaú apresenta o melhor NPS entre as cidades analisadas;
- Eusébio possui a menor taxa de resolução (55%).

# Dataset
Base de dados simulada de atendimentos ao cliente com registros de Canal, Cidade, Resolução e NPS.
